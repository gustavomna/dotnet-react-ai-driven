# Feature Prompt

Describe the feature you want to build. The `/create-prd` command reads this file as its starting point — be specific, but don't pre-design the solution.

## Business Requirements

- What problem does this solve?
- Who is it for?
- What does success look like (1–3 measurable outcomes)?

## Technical Constraints

- Must use the existing React 19 + Vite 8 frontend and .NET 10 Web API backend.
- List any non-negotiables: compliance rules, existing systems to integrate with, performance/latency targets.

## UI / UX Specs

- Key screens or flows.
- Accessibility expectations (WCAG 2.2 AA by default).
- Any design references (Figma links, screenshots).

## Endpoint Definitions

- Proposed routes (method + path) with a one-line description.
- Request/response shapes (rough is fine — the Tech Spec refines these).

## Out of Scope

- What this feature explicitly does NOT include.
